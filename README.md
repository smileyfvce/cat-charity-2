# QRKot - благотворительный фонд поддержки котиков

API для сбора пожертвований:
Пользователи отправляют донаты, которые автоматически автоматически распределяются по проектам - самый старый проект первым получает средства.

## Стек
- Python
- SQLAlchemy(async) + aiosqlite
- Alembic

## Как работает
1. Создаётся проект
2. Пользователь отправляет донат
3. Донат инвестируется в самый старый открытый проект
4. Если проект собирает нужную сумму - он закрывается, а остаток переходит в следующий открытый проект.
5. Если открытых проектов нет, то донат ждет открытия нового проекта.

## Как запустить
```
python -m venv venv
```
```
source venv\Scripts\activate
```
```
pip install -r requirements.txt
```
```
uvicorn app.main:app --reload
```
