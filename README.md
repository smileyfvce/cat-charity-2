# QRKot - благотворительный фонд поддержки котиков

API для сбора пожертвований:
Пользователи отправляют донаты, которые автоматически распределяются по проектам - самый старый проект первым получает средства.

## Какие функции выполняет

- Создание целевых проектов (название, описание, сумма).
- Приём пожертвований с комментарием.
- Автоматическое инвестирование донатов в открытые проекты
  (от старых к новым, по дате создания).
- Закрытие проекта при наборе нужной суммы; остаток доната
  идёт в следующий открытый проект.
- Если открытых проектов нет — донат ждёт нового проекта
  и автоматически вкладывается в него при создании.
- Просмотр списка всех проектов и пожертвований.
- Редактирование и удаление проектов с проверками:
  - нельзя редактировать закрытый проект, 
  - нельзя удалить проект с инвестициями, 
  - нельзя поставить сумму меньше уже вложенной.

## Стек
- Python 3.12
- FastAPI, Pydantic v2, pydantic-settings
- SQLAlchemy 2.0 (async) + aiosqlite
- Alembic (миграции)
- pytest, pytest-asyncio

## Как запустить
### Клонировать репозиторий:
```
git clone https://github.com/smileyfvce/cat-charity-2.git
```
### Перейти в директорию проекта:
```
cd cat-charity-2
```
### Создать виртуальное окружение:
```
python -m venv venv
```
### Активировать виртуальное окружение:
Windows(git bash)
```
source venv/Scripts/activate
```
Linux или MacOS
```
source venv/bin/activate
```
### Установить зависимости:
```
pip install -r requirements.txt
```
### Настроить переменные окружения:
Создайте файл `.env` в корне проекта
```
DATABASE_URL=sqlite+aiosqlite:///./fastapi.db
```
### Применить миграции:
```
alembic upgrade head
```
### Запустить сервер:
```
uvicorn app.main:app --reload
```
